# ADR-NNNN: Title in the form of a decision ("Use X for Y")

- **Status:** Proposed | Accepted | Superseded by ADR-NNNN
- **Date:** YYYY-MM-DD
- **Module:** which learning module produced this decision

## Context

What problem forces a decision now? Which constraints apply (correctness, cost, latency, security, scale)? State facts, not opinions. Two to five short paragraphs.

## Options considered

### Option A: name
- How it works, in two or three lines
- Pros
- Cons

### Option B: name
- …

(At least two real options. A "decision" with one option is a description.)

## Decision

The chosen option, in one sentence, then the reasoning that tipped it.

## Consequences

- **Positive:** what gets easier or safer
- **Negative:** what we now accept or must work around
- **Follow-ups:** what a production system would need beyond this POC

## Evidence

Benchmarks, tests or ground-truth checks that support the decision. Link to `bench/results/` or a test name.
